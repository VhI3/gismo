
Isogeometric Analysis for Structural Mechanics — Windows Port

This repository provides a Windows-compatible subset of the actively developed G+Smo library for isogeometric analysis (IGA). It is intended for my educational and experimental purposes, enabling me to explore structural mechanics examples on Windows systems using Visual Studio and the MSVC compiler.

🔧 Key Features:

    Minimal working build of G+Smo tailored for Windows

    Extended examples in 2D elasticity problems

    Integrated Matplot++ for plotting force–displacement responses

    Useful for learning and prototyping with IGA concepts

📌 Note:
G+Smo is an actively developed research codebase. This repository is a simplified, curated snapshot of the main project, designed to help new users get started with IGA and C++ development in a Windows environment.
